# ทดสอบบนมือถือจริง

ยังไม่ได้รันทดสอบรายการใด ตารางนี้เป็น checklist สำหรับ M2 เป็นต้นไป
ผลจาก emulator หรือข้อมูลจำลองใช้ตรวจ logic ได้ แต่ไม่ยืนยัน GPS, battery หรือการทำงานตอนปิดจอของมือถือจริง

| Test case | วิธีทดสอบ | Expected result |
| --- | --- | --- |
| ปฏิเสธ location | กด Start แล้วไม่อนุญาต | ไม่เริ่ม session ที่ดูเหมือนกำลังบันทึก แสดงวิธีเปิด permission |
| Approximate location | อนุญาตเฉพาะตำแหน่งคร่าว ๆ | แสดงข้อจำกัด ไม่อ้างระยะทางที่แม่นยำ |
| ปิด Location | ปิด Location ก่อน Start | แจ้งว่าใช้งาน GPS ไม่ได้และเปิดให้ลองใหม่ |
| เดินกลางแจ้ง | เดิน 5–10 นาทีและ Stop | มีจุดจริงในฐานข้อมูล เปิด session เดิมได้ |
| ปิดจอ | บันทึกระหว่างเดิน ปิดจออย่างน้อย 5 นาที | ตรวจ timestamp ว่ายังได้จุด ไม่ตรวจแค่ timer บน UI |
| สลับแอป | เปิดแอปอื่นระหว่างบันทึก | กลับมาเห็น session เดิมและจุดที่ได้รับในช่วงนั้น |
| Process death | ทำให้ process หยุดด้วยวิธีที่บันทึกไว้ | จุดที่เขียนแล้วอยู่ครบ เปิดใหม่แล้วแยกสถานะบันทึกจริงกับ interrupted ได้ |
| Force stop | ใช้ Force stop จาก Settings แล้วเปิดใหม่ | ไม่คาดหวัง GPS ต่อเนื่อง ข้อมูลที่บันทึกแล้วอยู่และระบุช่วงที่ขาด |
| GPS loss | ไปจุดอับสัญญาณแล้วกลับกลางแจ้ง | มีสถานะขาดช่วง ไม่มีเส้นหรือระยะทางสมมติข้าม gap |
| กดซ้ำ | กด Start / Stop รัว ๆ | ไม่สร้างสอง recorder หรือ session ซ้ำ Stop เสร็จแล้วไม่มีจุดเพิ่ม |
| เปิดแอปใหม่ | Stop ปิดแอป แล้วเปิดใหม่ | History และ summary อ่านจากข้อมูลเดิมได้ |
| Offline | ปิดอินเทอร์เน็ตแต่เปิด Location | ตรวจตาม location provider จริงและบันทึกเวลารอ fix รวมถึงข้อจำกัด |

Process death, ปัดออกจาก recent apps และ Force stop เป็นคนละกรณี ต้องบันทึกแยกกัน
เก็บ log ที่มีพิกัดจริงใน private-data/ ซึ่งถูก ignore และตรวจไฟล์ก่อน commit เสมอ
ข้อมูลจำลองที่ไม่มีพิกัดบ้านหรือกิจวัตรจริงสามารถเพิ่มเป็น fixture ใน test ได้
